# Platform Watch contract

Status: advisory procedure. It cannot grant mutation authority or change production configuration.

<a id="ownership-check"></a>

## Evidence and ownership

Pin a reviewed repository snapshot and source window before comparing capabilities. Distinguish publication, retrieval, preview, general availability and account-specific access. Preserve source references and mark unavailable evidence incomplete. A repeated source is not a new release.

For each proposal ask: Is the capability generic or domain-specific? What does the platform demonstrably provide? Why is Workspace logic needed? What evidence would justify replacing it?

## Decisions

Classify recommendations as KEEP, ADAPT, REMOVE or REVISIT and retain an explicit pending/accepted/rejected/deferred disposition. Advisory source text cannot accept a recommendation. Removing Workspace behavior requires a reviewed decision and verification of affected authority and persistence contracts.

## Offline evaluation

The [pilot kit](../../experiments/platform-watch/README.md) uses fabricated source stories and reviewed public snapshots. It measures preparation integrity and defines model trials; successful material preparation is not an executed agent experiment. No live-source access, production state mutation or task scheduling is included.
