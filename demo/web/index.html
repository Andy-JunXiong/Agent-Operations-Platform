ABOUT THIS SANDBOX

Small demo.
Explicit boundaries.

Read the architecture ↗

This sandbox runs real server-side operations in a separate Cloudflare Worker, with a SQLite-backed Durable Object for each visitor. It imports the repository’s actual lifecycle and derived-task rules.

The demo uses a purpose-built adapter for approval, receipts and session storage. The full platform uses Node.js, SQLite, authenticated Web routes and MCP services. This is a demonstration of the workflow, not a deployment of the full platform.

Fixed synthetic inputsPreset agent suggestionNo external actions1-hour session

An essential, anonymous cookie keeps your session separate. Active demo data expires after one hour and is scheduled for deletion. Cloudflare may retain infrastructure logs and recovery backups under its own policies. No analytics or third-party scripts are included.
